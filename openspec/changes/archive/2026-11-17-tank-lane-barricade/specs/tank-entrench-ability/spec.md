# Spec Delta

## REMOVED Requirements

### Requirement: Tank Entrench Activation
**Reason**: The Entrench ability is replaced by the Tank's lane-barricade ability.
**Migration**: Tank players use the new Barricade ability in the existing ability slot.

### Requirement: Entrench Prevents Movement
**Reason**: The Tank no longer gains a personal movement-lock effect from Entrench.
**Migration**: Use the deployed barricade to restrict movement through a lane.

### Requirement: Entrench Reduces Incoming Damage
**Reason**: The personal damage-reduction effect is removed with Entrench.
**Migration**: Use the unchanged Shield and Protection Dome abilities for defensive effects.

### Requirement: Entrench Cooldown
**Reason**: Entrench's cooldown is removed with the replaced ability.
**Migration**: The Barricade ability has its own cooldown as defined by the tank-lane-barricade-ability capability.
